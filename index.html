Install Hybrid

  1. Download the installer.Use Download for Windows above, then open Hybrid-Setup-3.21.78.exe from Downloads.
  2. Follow Windows setup.When it finishes, open Hybrid from the Start menu.
  3. Choose AI setup or open a workspace.Hybrid can install Codex or Claude Code and open the provider sign-in. You can also choose a local Ollama model.

OpenAI and Anthropic set model access and usage limits. Some models require an eligible paid plan. Claude accounts are for ages 18 and up.

Already using Hybrid? Click Update in the app.
